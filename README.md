# 오름

고3 학생이 평소 학습 습관을 수능 당일의 과목 순서와 시간 흐름에 점진적으로 맞추고,
해야 할 공부를 계획·알림으로 관리하도록 돕는 로컬 웹 프로그램의 기본 골격입니다.

## 공개 배포

이 저장소는 `render.yaml` Blueprint로 React 프런트엔드와 FastAPI API를 하나의 HTTPS 주소에 배포할 수 있습니다.
공개 환경에서는 브라우저별 익명 ID로 학습 데이터가 분리되며 `/var/data` 영구 디스크에 저장됩니다.

1. 이 저장소를 GitHub의 공개 또는 비공개 저장소로 올립니다.
2. Render Dashboard에서 **New → Blueprint**를 선택하고 GitHub 저장소를 연결합니다.
3. 초기 생성 화면에서 `GEMINI_API_KEY`와 `YES24_API_KEY`를 입력합니다.
4. Blueprint 적용 후 표시되는 `https://...onrender.com` 주소로 접속합니다.

Render 영구 디스크는 유료 웹 서비스에서만 사용할 수 있습니다. API 키와 로컬 `.env`, 기존 `backend/data/*.json`은
Git에 포함하지 않습니다. 브라우저 저장소를 삭제하면 익명 ID가 사라져 기존 서버 데이터에 다시 접근할 수 없으므로
중요한 기록의 내보내기 기능을 추가하기 전에는 브라우저 데이터를 삭제하지 마세요.

## 현재 범위

- 수능형 과목 시간 블록 API
- 학습 할 일 모델과 JSON 저장소
- 집중 세션 및 자세·졸음 감지 기능을 위한 API 자리
- 적응도, 과목 흐름, 자세 코치, 주간 습관을 보여주는 React 대시보드

> 현재 시간 블록은 제품 설계를 위한 시작 템플릿입니다. 실제 운영 전 해당 연도 수능 시행 공고의 공식 시간을 확인해야 합니다.

## 설계 원칙

- 초기 버전은 로그인과 외부 데이터베이스를 사용하지 않습니다.
- 저장이 필요한 데이터는 `backend/data` 아래 JSON으로 관리합니다.
- 카메라는 학생이 집중 세션을 시작한 동안만 사용합니다.
- 자세·졸음 감지는 브라우저 또는 라즈베리파이 안에서 처리하고 원본 영상을 저장하지 않는 방향으로 개발합니다.
- 자세 및 졸음 알림은 학습 보조 정보이며 의료 판단에 사용하지 않습니다.

## 새 라즈베리파이 5로 이전 및 원클릭 자동 설정

새로운 라즈베리파이에 아무런 개발 환경이 설치되어 있지 않아도, 포함된 자동화 스크립트를 통해 한 번에 설치 및 실행할 수 있습니다.

### 1. 현재 라즈베리파이에서 압축하기
프로젝트 루트에서 압축 스크립트를 실행하면 불필요한 가상환경(`backend/.venv`)과 `node_modules`를 제외하고 깔끔하게 압축됩니다.
```bash
./package_project.sh
# 상위 디렉터리에 study-rhythm-coach.tar.gz 생성됨
```

### 2. 새 라즈베리파이로 이동 및 압축 풀기
생성된 `study-rhythm-coach.tar.gz` 파일을 USB로 새 라즈베리파이의 `~/Documents/projects/`에 복사한 후:
```bash
mkdir -p ~/Documents/projects
cd ~/Documents/projects
tar -xzvf study-rhythm-coach.tar.gz
cd study-rhythm-coach
```

### 3. 원클릭 자동 환경 설치 (`setup.sh`)
아래 스크립트 하나로 Python 가상환경, 필수 패키지, Node.js v20 LTS, 프론트엔드 의존성이 자동 구성됩니다.
```bash
./setup.sh
```

### 4. 백엔드/프론트엔드 원클릭 동시 실행 (`start.sh`)
```bash
./start.sh
```
- 웹 브라우저: `http://<새라즈베리파이IP>:5173` (또는 로컬 `http://localhost:5173`)
- 백엔드 API 문서: `http://<새라즈베리파이IP>:8100/docs`
- 종료: `Ctrl + C`

## AI 학습 코치

상단 **AI 학습 코치**에서 기본 설정과 **공부 관리**에 등록한 미완료 작업·교재·페이지 범위·목표일을 바탕으로 7일 기본 계획을 만들 수 있습니다. 대화형 기본 설정에서는 그림·도표, 직접 문제 풀이, 말로 설명하기 등 선호하는 학습 방식을 복수 선택할 수 있습니다. 이 정보는 고정된 학습 유형을 판정하는 용도가 아니라, 인출 연습·간격 반복·오답 재풀이와 결합해 각 계획의 실행 방법을 맞추는 데 사용됩니다. 계획을 검토한 뒤 **이 계획 사용하기**를 누르면 홈의 **이번 주 학습 습관 → 오늘의 목표**에 날짜별 분량이 적용됩니다. 같은 교재의 기존 자동 배분은 해당 7일 동안 AI 계획으로 대체되어 중복 표시되지 않으며, 최신 수락 계획은 `backend/data/accepted-coach-plan.json`에 저장됩니다. 평소 공부 방법과 고민을 입력하면 저장된 성적·목표·학습 시간을 바탕으로 별도의 학습 조언도 받을 수 있습니다. 성적은 **기본 설정 → 목표 바꾸기**에서 수정합니다. 생성 중인 초안과 답변은 탭 이동 중 유지되며 페이지를 새로고침하면 초기화됩니다.

프로젝트 루트의 `.env`에 아래 설정을 추가한 뒤 백엔드를 재시작하세요. 기존 `.env`는 덮어쓰지 마세요.

```dotenv
GEMINI_API_KEY=발급받은_API_키
GEMINI_MODEL=gemini-3.5-flash
```

Gemini 키가 있으면 우선 사용하며, 없으면 기존 OpenAI 설정을 사용합니다. 키는 서버에서만 읽습니다. 사용 가능한 다른 Responses API 모델로 `OPENAI_MODEL`을 변경할 수 있습니다. 분석 버튼을 누르면 공부 방법과 프로필(자유 일정 메모 제외)을 설정된 AI 제공업체로 보내며 API 사용 요금이 발생할 수 있습니다. 키가 없으면 설정 미완료 안내를 표시합니다. AI 응답은 앱 서버 파일에 저장하지 않습니다.

Gemini 연동 문서: [콘텐츠 생성 API](https://ai.google.dev/api/generate-content)

연동 문서: [OpenAI Responses API](https://developers.openai.com/api/reference/typescript/resources/responses/methods/create)

## 시간별 학습 계획표

홈의 **이번 주 학습 습관 → 오늘의 목표**에는 공부 관리 작업, 수락한 AI 계획과 시간별 일정이 함께 표시됩니다. 날짜를 선택하면 해당 날짜의 일정이 목표 목록에 합쳐지며 완료 체크도 같은 곳에서 할 수 있습니다. 카드 아래 **일정 추가·수정**을 열면 00:00부터 24:00까지 한 시간 단위로 계획을 추가·수정·삭제할 수 있습니다. 처음 보는 날짜는 빈 시간표로 시작하며, 변경 사항은 날짜별로 `backend/data/timetable-YYYY-MM-DD.json`에 저장됩니다. 전체 계획을 삭제한 날짜는 빈 계획표로 유지됩니다. 시간은 같은 날 안에서 지정하며 겹치는 계획은 저장할 수 없습니다.

## 휴대폰 카메라

휴대폰에서 LAN IP의 `http://` 주소로 접속하면 브라우저가 카메라를 차단합니다. 휴대폰이 신뢰하는 인증서를 사용하는 HTTPS 주소로 접속하고 카메라 권한을 허용해야 합니다. 앱 내부 브라우저 대신 Chrome/Safari에서 직접 여세요.

카메라 미리보기는 서버 API 응답을 기다리지 않고 휴대폰에서 실행되며, 종료하면 카메라 트랙을 해제합니다.

상단 **집중 화면** 탭은 카메라 영상을 크게 표시하고 영상 위 내비게이션에 현재 시각, 집중 시간, 오늘 공부할 범위와 현재 집중 세션의 졸음 감지 횟수를 보여줍니다. 집중 시간은 촬영 중 초 단위로 증가하고 촬영을 종료하면 마지막 시간에 멈추며, 선택한 공부 범위의 과목으로 홈 **나의 학습 기록**에 자동 저장됩니다. 새 집중 촬영을 시작할 때 시간은 0으로 초기화됩니다. 공부 범위는 공부 관리 작업, 수락한 AI 계획과 오늘의 시간표에서 선택할 수 있습니다. 졸음 횟수도 새 집중 촬영을 시작할 때 0회로 초기화되며 영상은 저장하지 않습니다.

## 공부 시간 그래프와 집중 타이머

홈 상단의 **공부 시간**에서 일별(시간대별), 주간별(월~일), 월별(날짜별) 기록을 볼 수 있습니다. 날짜와 과목을 선택하거나 막대를 눌러 시간을 확인하세요. 가로로 긴 일별·월별 그래프는 좌우로 스크롤할 수 있습니다.

타이머에서 과목을 선택하고 **공부 시작 → 일시정지 / 이어서 공부 → 종료하고 저장**을 사용하세요. 진행 중 타이머는 브라우저에 보관되어 새로고침과 탭 이동 후에도 이어집니다. 종료하지 않으면 브라우저를 닫은 동안에도 시간이 흐르므로, 휴식할 때는 일시정지하세요. 저장 실패 시 기록을 유지하며 **다시 저장**할 수 있습니다. 저장한 기록은 `backend/data/study-sessions.json`에 보관합니다.

기간별 그래프는 실제 타이머 구간을 브라우저 현지 날짜로 나누어 계산하며, 일시정지 시간은 제외합니다. 기존 작업의 예상·완료 시간은 측정 날짜가 없어 이 그래프에 합산하지 않습니다.

## 시험 일정과 성적 관리

홈의 **나의 목표와 성적 → 시험 성적 보기**에서 연도·학년·시험을 선택하고 등급, 백분위, 원점수, 표준점수를 저장합니다. 2024~2026년 고1·고2·고3의 전국연합학력평가·평가원 모의평가와 고3 수능 일정 45건을 포함합니다. 성적은 시험 ID별 `backend/data/exam-results.json`에 저장하며, 빈 항목은 0점으로 바꾸지 않습니다. 아직 시행되지 않은 시험은 입력을 막습니다.

**공식 일정 갱신**은 EBSi의 실제 시험 일정 페이지를 조회합니다. 검증된 연도별 일정을 보관하고 이전 연도와 저장된 성적은 유지합니다. 통신 실패나 원문 구조 변경 시 기존 일정을 유지하며 오류를 표시합니다. 미래의 미발표 연도는 임의로 만들지 않습니다. 지역 자체 시험과 사설 모의고사는 포함하지 않습니다.

- 최신 일정: [EBSi 시험 일정](https://cloud.ebsi.co.kr/ebs/xip/xipa/retrieveExmSchedRngNext.ebs?tab=1&targetCd=D300)
- 2024년: [순창제일고 공개 일정](https://school.jbedu.kr/scje/M010401/view/6004015)
- 2025년: [부천고 교육계획서의 전국연합학력평가 일정](https://bch-h.goebc.kr/upload/bch-h/na/bbs_1308/2025/03/CFC956F0-2AC2-8609-5ADA-B388F5BABBB1.pdf)
- 2025년 6월 변경 반영: [교육부 일정 변경 안내](https://www.korea.kr/news/policyNewsView.do?newsId=148941577)

**목표 설정**에서는 시험 기록용 목표 대학·학과와 과목별 개인 목표를 저장합니다(`backend/data/exam-goal.json`). 최초에는 기본 설정의 목표를 가져옵니다. 이 화면의 개인 목표는 대학의 필수 합격 등급을 뜻하지 않습니다. 선택한 시험의 저장된 성적에서 등급은 낮아져야 하는 폭, 백분위는 높아져야 하는 폭을 보여줍니다. 과목별 등급 추이와 목록에서 연도와 응시 학년도 함께 확인할 수 있습니다.

공식 비교 자료는 현재 [어디가의 전북대 2025학년도 정시 공학계열 1·2 결과](https://www.adiga.kr/ucp/uvt/uni/univDetailSelection.do?menuId=PCUVTINF2000&searchSyr=2026&unvCd=0000025)를 지원합니다. 전기공학과의 공학계열 1 개편 이력은 [2025학년도 전형 변경 안내](https://www.adiga.kr/ucp/uvt/uni/univDetailSelection.do?menuId=PCUVTINF2000&searchSyr=2025&unvCd=0000025)에 근거합니다. 공개값은 70% 위치 학생의 영역별 성적으로, 각 과목의 독립적인 합격선이나 합격 확률이 아닙니다. 다른 대학은 개인 목표를 입력해 비교할 수 있습니다. 고1·2 성적이나 통합탐구를 과거 선택탐구 성적으로 자동 환산하지 않습니다.

## 시작일부터 목표일까지 자동 계획

**공부 관리 → 공부할 일 추가**에서 시작일과 목표일, 전체 예상 공부시간(분)을 입력하면 양 끝 날짜를 포함한 기간에 공부량을 균등하게 배분합니다. 페이지 범위를 입력하면 페이지도 중복·누락 없이 날짜별로 나눕니다. 예를 들어 5일 동안 100분·50페이지라면 하루 20분·10페이지입니다. 나누어떨어지지 않는 분량은 날짜별로 조금씩 차이를 두어 총량을 맞춥니다. 하루가 지나도 배정 범위는 바뀌지 않습니다.

타이머 오른쪽 **학습 습관**에서 요일을 누르거나 **오늘·내일**, 이전·다음 주, 날짜 선택으로 원하는 날짜의 자동 계획을 확인하고 체크할 수 있습니다. 체크는 작업 ID와 날짜별로 이 브라우저에 보관하며, 전체 작업 완료 및 타이머 실측 기록과는 별도로 관리합니다. 기존 작업의 시작일은 생성일(생성일이 목표일 이후라면 목표일)을 기준으로 표시합니다.

날짜별 공부량 자동 배분은 수동 시간별 계획표를 덮어쓰지 않습니다. 시작·목표일은 `backend/data/tasks.json`에 저장하며, 시작일이 목표일보다 늦으면 저장되지 않습니다.

공부 관리에서 교재 작업을 **완료**하면 완료일 당일까지의 계획과 체크 기록은 유지되고, 다음 날부터 해당 교재의 자동 계획과 교재를 출처로 한 AI 계획은 표시되지 않습니다. **되돌리기**를 선택하면 이전에 완료한 날짜별 분량은 그대로 둔 채 되돌린 날부터 목표일까지 남은 시간과 페이지를 다시 배분합니다. 완료·재개 날짜는 작업의 `planning_events`로 `backend/data/tasks.json`에 함께 저장됩니다.
